## AGENTS.md PATCH (add to section 4 or replace the "No external assets" rule)

```
### Art pass rules (Phase 9+)
- All models are generated by code (Parts, WedgeParts, Cylinders, Balls, Terrain, ParticleEmitters, Beams, Lights). No Toolbox models.
- Every visual asset goes through a builder module in src/shared/art/ (e.g. AstronautBuilder, SweeperCartBuilder, PetBuilder).
- Every builder reads src/shared/config/Assets.lua. If an entry has a MeshId / ModelId / Texture / Sound id, the builder uses it; otherwise it falls back to the procedural code version. This lets the human replace placeholders with custom Blender/Studio assets later without touching game logic.
- All colors come from src/shared/config/Palette.lua. No hardcoded colors elsewhere.
- Part budget (hard limits): each pet <= 25 parts, each tool <= 15 parts, each robot/vehicle <= 40 parts, each station <= 60 parts. Anchored where possible, CanQuery/CanTouch false on decorative parts, CollisionGroup "Decor" for non-colliding details.
- Do not copy any existing commercial game's models or names. Use the reference only for style direction.
```

## VISUAL REFERENCE (what the screenshots show)

Style direction taken from the reference images (style only, not to be copied 1:1):
- **World**: a vast pale gray-lavender lunar surface under a pure black sky. Soft rounded hills and a curved horizon. A large Earth-like planet in the sky and a bright sun glare on the horizon.
- **Surface detail**: many tiny scattered pebbles, small crater dents, and footprints across the ground. Faint yellow painted road/guide lines.
- **Cleaning feedback**: a cleaned patch looks smoother and lighter than the surrounding dusty ground, with a clear edge. This visible "before/after" is the main satisfaction of the game.
- **Character**: chunky stylized astronaut. White suit with red stripe bands on arms/legs, gray backpack and gloves, round helmet with a dark glossy visor.
- **Cleaning vehicle**: a compact push-cart sweeper. Cream/white body with a dark teal lower section, an orange accent panel, black wheels with orange hubs, and a wide orange rotating brush in front that throws small gray pebbles.
- **Overall look**: clean, friendly, slightly toy-like proportions, soft lighting, high contrast between pale ground, white suit, orange accents, and black space.
